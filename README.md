### Compilación
- Compilador: pdfLaTeX (Overleaf o TeX Live).
- Archivo principal: `EV-PRAC-01/main.tex`
- Dependencias: babel (spanish), geometry, longtable, array, graphicx.
- Comandos, desde la carpeta `EV-PRAC-01/`: `pdflatex main.tex`, y luego `pdflatex main.tex` otra vez (para ajustar la tabla). No usa bibliografía.
