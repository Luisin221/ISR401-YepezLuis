# FORM-TL-01

## Taller de identificación y clasificación de tipos de requisitos

**Asignatura:** Ingeniería de Requisitos (ISR-401)

**Tipo:** Actividad formativa

**Semana:** 1

## Objetivo

Identificar y clasificar los requisitos de una plataforma de gestión de citas médicas, aplicando los fundamentos de Ingeniería de Requisitos.

## Actividades

- Clasificación de 20 enunciados.
- Identificación de requisitos funcionales, de calidad y restricciones.
- Clasificación por producto/proceso y sistema/software.
- Mejora de cinco requisitos de calidad.
- Comparación y discusión de resultados.
